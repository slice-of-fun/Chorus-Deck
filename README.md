# 🎵 Chorus Deck

Welcome to **Chorus Deck**! 

## ✨ Features

- 🎵 Music Recommendation
- 🔐 Account Login & Synchronization
- 📝 Comprehensive Music Management (History, Favorites, Playlists, Daily Recommendations)
- 🎨 Beautiful UI with Light/Dark Themes & Mini Mode
- 🎼 Immersive Desktop Lyrics & Status Bar Control
- 🚀 Multi-Platform Support (Desktop, Web, Mobile)
- 🎧 High-Quality Audio & EQ Customization

## 🚀 Getting Started

### Prerequisites
Make sure you have Node.js installed.

### Installation

Install the dependencies:

```bash
npm install
```

### Running Locally

To start the development server:

```bash
npm run dev
```
